@ch1 | 第一章 | 翠亨少年 | 1866 — 1892
1866年11月12日， / 孙中山出生在广东省香山县翠亨村 | 一户普通的农家。
他名文，号逸仙。 / 幼年家境贫寒， / 常随父亲下田劳作。

1879年， / 少年孙中山随母亲远渡重洋， / 投奔在檀香山垦荒经商的兄长孙眉。
在那里，他“始见轮舟之奇，沧海之阔”， / 从此萌生了探求新知、改造中国的志向。

回国后，他先后在广州、香港学医。
1892年，他以第一名的成绩， / 毕业于香港西医书院。
求学期间， / 他常与陈少白、尤列、杨鹤龄 | 纵论时政，倡言革命， / 被人称作“四大寇”。

@ch2 | 第二章 | 上医医国 | 1894 — 1895
行医，可以救人； / 可是国家的病，又该由谁来医治？

1894年，孙中山上书李鸿章， / 提出“人能尽其才，地能尽其利， / 物能尽其用，货能畅其流”的主张， / 却没有得到回应。
这一年，甲午战争爆发， / 清军节节败退，民族危机空前深重。

11月，他在檀香山创立兴中会， / 第一次喊出了“振兴中华”的时代强音。

1895年，他策划的广州起义 / 因消息泄露而失败， / 战友陆皓东英勇就义。
孙中山被迫流亡海外， / 从此走上了职业革命家的道路。

@ch3 | 第三章 | 三民主义 | 1896 — 1905
1896年10月， / 孙中山在伦敦被清政府驻英公使馆 | 诱捕囚禁。
危急关头，他的老师康德黎四处奔走， / 英国报界纷纷声援， / 他才得以脱险。
“伦敦蒙难”， / 让孙逸仙的名字传遍了世界。

此后，他留在欧洲考察社会政治， / 博览群书， / 三民主义的思想由此逐步形成。

1905年8月， / 中国同盟会在东京成立， / 孙中山被推举为总理。
“驱除鞑虏，恢复中华， / 创立民国，平均地权”， / 成为革命党人共同的纲领。
在《民报》发刊词中， / 他第一次提出了 | 民族、民权、民生三大主义。

@ch4 | 第四章 | 屡败屡战 | 1906 — 1911
从1906年到1911年， / 革命党人在两广、云南等地 | 接连发动武装起义。
1907年镇南关之役， / 孙中山亲临前线，登上炮台，亲手发炮。

一次次起义，一次次失败。
他奔走于南洋和欧美各地， / 向华侨宣传革命，筹募经费。

1911年4月，广州黄花岗起义， / 一大批青年志士慷慨赴死。
孙中山后来写道： / “是役也，碧血横飞，浩气四塞， / 草木为之含悲，风云因而变色。”

@ch5 | 第五章 | 创立民国 | 1911 — 1912
1911年10月10日， / 武昌起义一举成功，各省纷纷响应。
此时，孙中山正在美国筹款。 / 得知消息后，他先赴欧洲开展外交活动， / 年底回到上海。
有人问他带回了多少钱，他回答： / “予不名一钱也， / 所带回者，革命之精神耳！”

1912年1月1日， / 孙中山在南京宣誓就任 | 中华民国临时大总统。
2月12日，清帝宣布退位。 / 在中国延续了两千多年的君主专制制度， / 就此终结。

他主持制定《中华民国临时约法》， / 以根本大法的形式， / 确立了主权在民的原则。
为了换取清帝退位与南北统一， / 孙中山依照约定，辞去临时大总统之职， / 由袁世凯继任。

@ch6 | 第六章 | 捍卫共和 | 1913 — 1922
然而，共和之路布满荆棘。
袁世凯专权独裁，复辟帝制； / 此后军阀割据，战乱不休。
孙中山发动二次革命，组织中华革命党， / 讨伐袁世凯； / 又南下广州，举起护法的旗帜。

1915年，他与宋庆龄在东京结为伴侣， / 从此风雨同舟。

在最艰难的岁月里，他潜心著述， / 写成《建国方略》， / 为中国描绘出铁路纵横、港口林立的 | 现代化蓝图。

1922年，陈炯明部在广州叛变， / 炮轰总统府。 / 孙中山登上永丰舰，坚守五十余日。

@ch7 | 第七章 | 黄埔建军 | 1923 — 1924
屡经挫折，孙中山认识到， / 革命必须依靠新的力量。

1924年1月， / 中国国民党第一次全国代表大会 | 在广州召开。
大会决定联合苏俄、与中国共产党合作、 | 扶助农工， / 第一次国共合作由此实现。

同年6月，黄埔军校举行开学典礼。
孙中山勉励学生： / 不存升官发财之心， / 只做救国救民的事业。

这一年，他还创办了国立广东大学， / 也就是今天的中山大学， / 并亲笔题写校训： / 博学、审问、慎思、明辨、笃行。

@ch8 | 第八章 | 抱病北上 | 1924 — 1925
1924年11月， / 为谋求国家的和平统一， / 孙中山抱病北上。
他主张召开国民会议， / 废除不平等条约。

一路劳顿，他的病情急剧恶化。 / 抵达北京后，被确诊为癌症晚期。

1925年3月12日上午九时三十分， / 孙中山先生在北京逝世， / 终年五十九岁。
弥留之际，他仍在断断续续地呼唤： / “和平…… {和平。} [0.75] / 奋斗…… {奋斗。} [0.75] / 救中国……” {救中国。}

他在遗嘱中说： / “余致力国民革命，凡四十年， / 其目的在求中国之自由平等。
积四十年之经验， / 深知欲达到此目的， / 必须唤起民众， / 及联合世界上以平等待我之民族， / 共同奋斗。”

@end | 终章 | 天下为公 | 1929 — 2026
1929年6月， / 孙中山先生的灵柩奉安于南京紫金山。
陵门之上，镌刻着他手书的四个大字—— / 天下为公。
三百九十二级石阶，层层向上， / 一如他走过的道路。

他一生奔走，四十年如一日。

他留下的，是“振兴中华”的呼声， / 是“博爱”的胸怀， / 是“天下为公”的理想。

今天，海峡两岸和全世界的中华儿女， [0.9] / 依然深深怀念着这位伟大的先行者。

2026年， / 是孙中山先生诞辰一百六十周年。

革命尚未成功，同志仍须努力。

先生之风，山高水长。
