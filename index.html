物理模型（全部由公式实时计算）

1. 时空：Schwarzschild 度规

ds² = −(1 − 2M/r) dt² + (1 − 2M/r)⁻¹ dr² + r² (dθ² + sin²θ dφ²)

事件视界 r = 2M，光子球 r = 3M，最内稳定圆轨道 ISCO r = 6M。

2. 光线：零测地线方程（逐像素反向追踪）

由球对称性，每条光线位于过黑洞中心的平面内。令 u = 1/r，零测地线方程化为 Binet 形式：

d²u/dφ² = −u + 3M u²

在 GPU 着色器中对每个像素用四阶 Runge–Kutta 积分（自适应步长 Δφ = Δφ₀·5/(1+12u)，光子球附近为 Δφ₀；与高精度参考解相比主像方向误差 ≲ 10⁻⁵ rad，远低于一个像素）， 并用三次 Hermite 插值精确求出光线穿过赤道面（吸积盘）的位置与逃逸到无穷远的方向。 任意阶的高阶像（盘的背面、光子环）都自然出现。r < 3M 且向内运动的光线必定落入视界。

相机是该点的局域静止观测者（或运动观测者），像素方向定义在其正交标架中； 径向分量按 √(1 − 2M/r) 换算到坐标空间，冲击参数 b = r sinψ / √(1 − 2M/r)。

3. 观测者运动与光行差

可选静止悬停、开普勒圆轨道（v = √(M/(r − 2M))）或从无穷远自由下落（v = √(2M/r)）。 像素方向经狭义相对论光行差变换到静止标架： n = n′ + [(γ − 1)(n′·β)/β² − γ] β，频率因子 1 / [γ(1 − β·n′)]。

4. 吸积盘：Novikov–Thorne / Page–Thorne 薄盘

盘内气体在赤道面做开普勒圆周运动，Ω = √(M/r³)，ut = 1/√(1 − 3M/r)。 内边缘零力矩，辐射通量（x = √r，x₀ = √rin）：

F(r) ∝ [ x − x₀ + (√3/2) ln( (x+√3)(x₀−√3) / ((x₀+√3)(x−√3)) ) ] / ( r^{5/2} (r − 3M) )

局域为黑体，T(r) ∝ F(r)1/4，峰值约在 r ≈ 9.55M；湍流结构按局域开普勒角速度差动旋转。

5. 红移、多普勒与相对论集束

g = νobs/νem = √(1 − 3M/r) / [ √(1 − 2M/robs) · (1 − Ω Lz/E) ]

其中 Lz/E 由每条光线的守恒量直接得到。由于 Iν/ν³ 是洛伦兹不变量， 温度为 T 的黑体在观测者看来正好是温度为 gT 的黑体——因此颜色与亮度（相对论集束）都由 Planck 定律精确给出。 颜色通过 Planck 谱与 CIE 1931 色匹配函数积分得到，再转换到线性 sRGB。 可选 Chandrasekhar 电子散射临边昏暗 I(μ) ∝ 1 + 2.06μ（μ 在气体共动系中计算）。

6. 光行时延与背景星空

沿光线积分 dt/dφ = 1 / [b u² (1 − 2Mu)] 得到坐标时延，盘面图案取发射时刻的状态。 背景为程序化银河（老年/年轻星族黑体谱 + Hα/Hβ/[OIII] 发射线 + 尘埃消光）与约 50 万颗恒星； 来自无穷远的光对静止观测者有蓝移 g = 1/√(1 − 2M/r)，颜色同样按 Planck 谱/谱线波长精确移动。 恒星按点源处理，像素足迹由光线方向的屏幕导数给出，因此透镜放大时通量守恒。
